# AI Memory Core 🧠

ИИ-Ассистент с долговременной памятью на базе локальной языковой модели (LM Studio) и реляционной базы данных Microsoft SQL Server (MSSQL).

Проект автоматически анализирует диалог с пользователем, извлекает важные факты, привычки, предпочтения или характеристики окружения, сохраняет их в базу данных и динамически подмешивает релевантные воспоминания в системный контекст модели при последующих запросах.

---

## 🛠 Требования к системе

1. **Python 3.10 или выше**
2. **Microsoft SQL Server** (LocalDB, Express или полная версия)
3. **Microsoft ODBC Driver 17 for SQL Server**
4. **LM Studio** с запущенным локальным сервером (рекомендуются модели уровня 7B/8B, например Llama 3 или Mistral, для стабильного извлечения фактов).
